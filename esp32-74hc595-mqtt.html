Vì sao dùng 74HC595?

Vấn đề

ESP32 có nhiều GPIO nhưng điều khiển 8–16 LED/relay trực tiếp tốn chân, dây rối, khó mở rộng.

Giải pháp

Shift register 74HC595: nạp tuần tự 8 bit qua 3 dây (Data, Clock, Latch), rồi song song ra Q0–Q7.

  • 1 chip = 8 đầu ra · Daisy-chain Q7S → DS chip sau = 16, 24, … kênh.
  • LED demo lab · Relay module cho tải thật (đèn, quạt, khóa…) — cần driver / opto, không nối AC trực tiếp vào 74HC595!

74HC595 — chân DIP-16 (nhìn từ trên, notch phía trên)

┌───────────⊙───────────┐ Q1 1│ │16 VCC (+3V3 / +5V) Q2 2│ │15 Q0 Q3 3│ 74HC595 │14 DS (SER / Data) Q4 4│ Shift Register │13 OE (Output Enable, ACTIVE LOW) Q5 5│ │12 STCP (RCLK / Latch) Q6 6│ │11 SHCP (SRCLK / Clock) Q7 7│ │10 SRCLR (MR / Clear, ACTIVE LOW) GND 8│ │ 9 Q7S (serial out → chip sau) └───────────────────────┘

Một số datasheet/board ghi SER=DS, RCLK=STCP, SRCLK=SHCP, MR=/SRCLR — cùng chức năng.

Giải thích từng chân 74HC595

VCCNguồn logic chip. Lab ESP32: nối 3V3. Module 5V: dùng 5V (mức tín hiệu ESP32 3.3V thường vẫn nhận được).
GNDMass chung với ESP32. Bắt buộc chung GND nếu không tín hiệu “lơ lửng”.
DSData / SER — từng bit tuần tự từ MCU. Mỗi cạnh lên của SHCP, 1 bit vào thanh ghi dịch.
SHCPClock dịch (SRCLK) — xung clock đẩy bit vào shift register.
STCPLatch (RCLK) — cạnh lên: copy 8 bit từ shift → thanh ghi lưu trữ → ra chân Q0–Q7.
OEOutput Enable, active LOW. OE=0 → Q0–Q7 hoạt động. OE=1 → ngõ ra Hi-Z (tắt). Lab: nối GND.
SRCLRClear, active LOW. =0 xóa shift register. Lab: nối VCC (không xóa).
Q0–Q78 ngõ ra song song (LED anode / tín hiệu relay). Q0 = bit LSB sau khi latch (tùy thứ tự MSBFIRST).
Q7SSerial out — bit tràn ra ngoài (sau 8 xung clock). Nối sang DS chip kế để daisy-chain.

Luồng dữ liệu trong 1 chip (logic)

MCU ──DS──▶ [ Shift register 8-bit ] ──Q7S──▶ (sang chip sau) ▲ │ SHCP (clock) │ cạnh lên STCP (latch) ▼ [ Storage 8-bit ] │ ┌───┬───┬───┼───┬───┬───┬───┐ Q0 Q1 Q2 Q3 Q4 Q5 Q6 Q7 │ │ │ │ │ │ │ │ LED LED … (hoặc IN relay)
  • shiftOut() chỉ đẩy bit vào shift register — LED chưa đổi ngay.
  • Khi STCP HIGH (latch), Q0–Q7 mới cập nhật đồng loạt → tránh nhấp nháy giữa chừng.
  • OE=GND luôn bật output; muốn “tắt hết nhanh” có thể kéo OE lên HIGH (không bắt buộc trong lab).

Ma trận / hàng LED — mapping kênh

Mask 16-bit (sau 2 lần shiftOut MSBFIRST trong code mẫu): bit15 bit14 … bit8 │ bit7 bit6 … bit0 ────────────────────┼───────────────── SR2:Q7 … SR2:Q0 │ SR1:Q7 … SR1:Q0 LED15 … LED8 │ LED7 … LED0 Ví dụ kiosk kho: A-01 → ledIndex 0 → bit0 → SR1 Q0 A-08 → ledIndex 7 → bit7 → SR1 Q7 ← LED hàng 1, cuối cùng A-09 → ledIndex 8 → bit8 → SR2 Q0 A-16 → ledIndex 15 → bit15 → SR2 Q7 Bật nhiều kênh: mask = (1<<0)|(1<<3)|(1<<7) hoặc action "set" / "setMany"

Đây là “hàng LED song song” (mỗi Q một LED), không phải quét hàng-cột LED matrix 8×8. Cùng nguyên lý 74HC595; matrix quét cần thêm transistor hàng + timer.

Tính dòng LED + điện trở

Công thức: I ≈ (VCC − Vf_LED) / R Ví dụ LED xanh lá, Vf ≈ 2.0 – 2.2 V, VCC = 3.3 V, R = 220 Ω: I ≈ (3.3 − 2.1) / 220 ≈ 5.5 mA ← an toàn cho 74HC595 R = 100 Ω → I ≈ 12 mA (sáng hơn, nhưng 8 LED ≈ 96 mA > 70 mA package → nóng/hỏng 74HC595!) R = 470 Ω → I ≈ 2.5 mA (đủ nhìn trong nhà, tiết kiệm nguồn) Tổng 1 chip (8 LED cùng sáng): I_chip ≈ 8 × I_LED Tổng 2 chip (16 LED cùng sáng): I_leds ≈ 16 × I_LED (+ dòng MCU/Wi‑Fi)

Checklist chống sụp nguồn

1. USB / adapter

Cáp ngắn, cổng ≥ 1 A. Tránh hub không nguồn khi demo Wi‑Fi + nhiều LED.

2. Điện trở LED

Luôn có R · ưu tiên 220–470 Ω. Đừng full-on 16 LED không R.

3. Tách nguồn tải

≥3 chip LED sáng mạnh hoặc mọi relay: nguồn riêng, chung GND.

4. Tụ / dây

VCC–GND gần 74HC595: tụ 100 nF. Dây nguồn ngắn, đủ dày.

5. Phần mềm

Không bật hết kênh nếu không cần · clear khi xong · tránh spike MQTT+full LED.

6. Công thức nhớ

Số 74HC595 ≈ không giới hạn tín hiệu; dòng LED/relay mới giới hạn.

Lỗi nối chân thường gặp

OE quên kéo GND

OE nổi / kéo HIGH → Q0–Q7 Hi-Z → LED không sáng dù code đúng.

SRCLR nối GND

Clear luôn active → thanh ghi bị xóa liên tục → không giữ trạng thái.

Thiếu Q7S→DS

Chip 2 không nhận data → LED8–15 tắt; chỉ còn 8 LED đầu.

Clock/Latch không song song

SHCP/STCP phải chung cả 2 chip — nếu chỉ nối 1 chip, daisy-chain lệch pha.

LED ngược cực

Anode phải về Qx, cathode về GND (+R). Nối ngược → không sáng.

Không chung GND

ESP32 và 74HC595 khác mass → mức logic sai, chip nóng / hành vi lạ.

② Ghi LED — writeShift / setLed / clearAll

uint16_t ledMask = 0;  // 16 bit = 16 kênh LED (bit0=LED0 … bit15=LED15)

void writeShift(uint16_t mask) {
  digitalWrite(PIN_RCLK, LOW);              // hạ Latch trước khi đẩy bit
  shiftOut(PIN_SER, PIN_SRCLK, MSBFIRST, (mask >> 8) & 0xFF); // byte → chip 2
  shiftOut(PIN_SER, PIN_SRCLK, MSBFIRST,  mask       & 0xFF); // byte → chip 1
  digitalWrite(PIN_RCLK, HIGH);             // STCP HIGH = chốt ra Q0–Q7
}

void setLed(uint8_t index, bool on) {       // bật/tắt 1 kênh
  if (on) ledMask |=  (1u << index);
  else    ledMask &= ~(1u << index);
  writeShift(ledMask);
}

void clearAll() { ledMask = 0; writeShift(ledMask); }  // tắt hết

shiftOut = đẩy bit tuần tự · PIN_RCLK = chân Latch (STCP).

③ connectWifi() — nối Wi‑Fi

void connectWifi() {
  WiFi.mode(WIFI_STA);                      // chế độ Station (client)
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);     // bắt đầu kết nối
  unsigned long start = millis();
  while (WiFi.status() != WL_CONNECTED      // chờ đến khi có IP
         && millis() - start < 20000) {
    delay(250);
  }
}

④ connectMqtt() — đăng ký MQTT broker (chi tiết)

void connectMqtt() {
  // 1) Tên client duy nhất trên broker (tránh trùng)
  String clientId = String("shelf-") + DEVICE_ID + "-" + String(chipId, HEX);

  while (!mqtt.connected()) {
    // 2) ĐĂNG KÝ / kết nối tới broker (MQTT_HOST:MQTT_PORT)
    if (mqtt.connect(clientId.c_str())) {

      // 3) SUBSCRIBE = đăng ký NHẬN lệnh trên topic
      String topic = "warehouse/" + DEVICE_ID + "/light";
      mqtt.subscribe(topic.c_str(), 1);   // QoS 1

      // 4) PUBLISH status = báo “tôi online” (tuỳ chọn nhưng hữu ích)
      mqtt.publish("warehouse/node-A/status", "{\"online\":true}");

      Serial.printf("MQTT ok → %s\n", topic.c_str());
    } else {
      Serial.printf("MQTT fail rc=%d\n", mqtt.state());
      delay(2000);   // thử lại
    }
  }
}

connect = vào phòng chat broker · subscribe = đăng ký nghe topic · publish = gửi tin đi.

⑤ setup() — gắn callback + gọi đăng ký

void setup() {
  pinMode(PIN_SER, OUTPUT);     // 3 chân tới chip 74HC595
  pinMode(PIN_SRCLK, OUTPUT);
  pinMode(PIN_RCLK, OUTPUT);
  clearAll();                   // LED tắt lúc mới boot

  Serial.begin(115200);         // in log ra Serial Monitor
  connectWifi();                // ③

  mqtt.setServer(MQTT_HOST, MQTT_PORT);  // chỉ định broker
  mqtt.setBufferSize(512);               // đủ chỗ chứa JSON
  mqtt.setCallback(handleMqtt);          // khi có tin → gọi ⑦
  connectMqtt();                         // ④ đăng ký + subscribe
}

setCallback(handleMqtt) = “khi broker đẩy tin về, chạy hàm handleMqtt”.

⑥ loop() — giữ kết nối + nhận tin

void loop() {
  if (!mqtt.connected()) connectMqtt();  // mất mạng → đăng ký lại
  mqtt.loop();   // BẮT BUỘC: đọc tin từ broker → gọi handleMqtt

  // (tuỳ chọn) logic nhấp nháy LED theo thời gian
  if (blinking) { … setLed bật/tắt theo chu kỳ … }
}
  • Quên mqtt.loop() → không bao giờ vào handleMqtt (LED không đổi).

Payload JSON — 1 kênh

void handleMqtt(char* topic, byte* payload, unsigned int length) {
  // A) In raw ra Serial (debug lab)
  Serial.write(payload, length);

  // B) Đổi chuỗi JSON → object
  JsonDocument doc;
  if (deserializeJson(doc, payload, length)) {
    Serial.println("JSON err");
    return;   // sai JSON → bỏ qua, không đụng LED
  }

  const char* action = doc["action"] | "";

}

Chưa điều khiển LED ở bước này — chỉ nhận tin và parse.

⑦ handleMqtt() — bước 2: rẽ nhánh theo action

if      (action == "on")      setLed(ledIndex, true);
else if (action == "off")     setLed(ledIndex, false);
else if (action == "blink")   startBlink(ledIndex, durationMs, hz);
else if (action == "clear")   clearAll();
else if (action == "set") {
  ledMask = doc["mask"];
  writeShift(ledMask);          // 1 lần ghi cả bảng
}
else if (action == "setMany") {
  bool state = doc["state"] | true;
  for (int idx : doc["channels"].as<JsonArray>())
    setLed(idx, state);         // bật/tắt từng kênh trong list
}

Mỗi action = một việc rõ ràng → sinh viên dễ thêm lệnh mới (ví dụ toggle).

Checklist an toàn (relay)

Logic thấp

74HC595 / ESP32 chỉ 3.3V logic. Relay module thường cần transistor + diode flyback.

Tải AC

Dùng module relay cách ly, vỏ kín, không chạm cực AC khi thí nghiệm.

Chung GND

ESP32, 74HC595, module relay phải chung mass (GND).

Công suất

Không lấy nguồn relay từ chân 3V3 ESP32 nếu nhiều kênh — dùng nguồn 5V riêng.

Bài tập sinh viên

  1. Bắt buộc: Subscribe topic nhóm mình, bật/tắt LED theo on/off/clear.
  2. Nâng cao: Thêm action set (mask) và setMany — demo bật 4 relay cùng lúc bằng 1 payload.
  3. Ứng dụng: Viết script Python/Node publish theo lịch (ví dụ sáng bật 0–3, tối clear).
  4. Mở rộng: Thêm topic .../status báo lại mask hiện tại mỗi khi đổi.
